### Objective 3: Software Design

Determine a design model through brainstorming or research.

#### Option 1: Variable Control Loop

Each iteration of the main loop would scan for new data, calculate a result, and carry out one action. Global variables would hold flags and other information used by that calculation.

#### Option 2: State Control Loop

This approach is similar to the variable control loop, but adds explicit states. That would allow the robot to carry out a more complex sequence of actions with limited decision-making. For example, if a pushed-back state becomes active, the code could focus on escaping by choosing between pushing harder, backing up left, or backing up right.
